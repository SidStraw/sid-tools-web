支援範圍

    

      首版支援直接具名匯出的 React function／arrow、同檔 interface／type literal
      與解構參數。型別顯示宣告語法，未代替 TypeScript compiler。預設值只確認字串、數字、布林、null
      等參數字面值；運算、匯入、wrapper 或繼承可能顯示未知／不完整。
    

    

      範例只檢查必填、已宣告欄位、基本型別及字面值
      union。函式、物件與引用型別等超出範圍者顯示未知；沒有問題不表示元件行為或完整型別檢查已通過。後續
      defaultProps 賦值與執行期修改不在參數預設的分析範圍。
