06 ／ 結構、未解析與支援邊界

PATH / ORIGINAL SOURCE RANGE
覆蓋範圍與官方 CLI 固定案例

    本機官方 Compose v5.5.0 已在隔離環境執行 23 組人工案例、46 次 config。Primary：config --format json --no-env-resolution --no-path-resolution；secondary 額外 --no-interpolate。在此版本，secondary 會接受 primary 拒絕的 missing refs／cycles，所以其 exit 0 不能作為一致性證明。固定結果與逐項差異見專案 docs/validation/stw-8/cli/README.md、results.json 與 comparison.md；產品不執行 CLI。

    Primary 可用隔離檔案解析 include／extends，也會對缺少環境變數代空值／解析 default；本工具不讀環境／檔案，所有 $VAR／${…}（含 defaults）仍未解析，絕不以空字串冒充有效值。$$ 只代表 escape；動態 graph 名稱仍保守未知。Include／extends／多 -f 合併／env_file 不處理，x-* 明示忽略，其他不支援設定保守 partial。

    Complete 僅代表有限靜態子集，不是完整 schema／resolved application／啟動／健康驗證。CLI config 接受 service_healthy 而沒有 healthcheck、接受 external resource 名稱，也不能證明服務成功或資源存在。無 daemon／pull／up／create／filesystem probes；不把官方參考當 runtime 依賴。
