Monorepo 相依圖

從本機匯出的報告追查：哪些 workspace 引入這個套件？是多個版本，還是相同版本的 peer context？

載入本機報告

先在本專案完成建置，再執行 mise exec -- node apps/dependency-graph/dist/cli.mjs /path/to/repo > dependencies.json。支援 pnpm lockfile 9.0，含雙 YAML 文件。CLI 與使用說明見專案 README。

報告只在裝置處理，不上傳或保存。

依賴與來源

多版本與 peer context

版本不同與 peer context 不同分開列出。重複不代表可以刪除；lockfile 的 optional 依賴也不代表已在目前裝置安裝。

如何解讀

每個引入來源顯示一條最短路徑；直接相依為一步，間接相依會顯示中間套件。節點的所有直接邊另列於下方，循環不會無限展開。

預設 CLI 隱藏 workspace 實際路徑，但套件名稱及依賴關係仍在報告內。若明確加上 --include-workspace-paths，將包含相對路徑；分享前請檢查。來源行號對應匯出當時的 lockfile。

本工具不讀取或執行 repo 的 scripts，不推測缺少的依賴，也不自動去重或修改專案。未解析與過期 manifest 會顯示診斷。
