OpenAPI Mock API 情境服務

用同一份測試合約切換成功、錯誤與延遲回應。服務在你的電腦執行，設定可在重啟後還原。

啟動本機服務

在此專案完成建置後，使用已確認可公開測試的 JSON 合約。請在終端機印出的本機網址開啟此頁，再連線管理情境。 

mise exec -- pnpm build
mise exec -- node apps/mock-runtime/dist/cli.mjs contract.json --state mock-state.json --seed demo-1 --confirm-test-data

僅監聽 127.0.0.1，預設埠 4010。按 Ctrl-C 停止；再次使用相同合約、state 路徑與 seed 啟動即可還原。重啟不會重新抽取隨機回應。

支援有限 OpenAPI 3.0.x JSON 回應；不驗證請求或認證、不呼叫正式 API。來源範例不會自動匿名化。正式工具站提供說明，請使用 CLI 印出的本機網址操作。
