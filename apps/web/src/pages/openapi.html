01 ／ 這次合約如何改動？

BEFORE → AFTER · 3.0.x ONLY

固定案例都是人工合成，不是外部服務或客戶資料。選案例後按比較。

YAML 1.2 core JSON-compatible grammar（包含 JSON 輸入，不是 strict JSON）。拒絕 aliases／anchors／tags／directives／多文件／merge／複雜鍵／重複鍵。每側 1,000,000 UTF-16 字碼單元，token depth 100／objects 200,000／entries 10,000／scalar source 100,000；先檢查 token，再建立文件。

按比較才建立獨立 worker，最多等待 20 秒。

支援邊界與固定判斷規則

    僅 3.0.x。內部 $ref 有界解析：最多 16 hops／50,000 resolutions；missing／external／ref-only cycles／recursive schema 都可能 unknown，即使未變。$ref siblings 依 3.0 忽略並提示。Unsupported facets（composition／constraints／format／default／schema-valued additionalProperties）、serialization、headers、extensions 可能未變也 unknown；security／server 變動需審查。最多 50,000 比較 pairs、schema depth 64、5,000 findings；運算預算耗盡可保留明示不完整的 findings，finding／parser 超限不回傳截斷成功。
