Input 可接受範圍
String → String!：breaking；反向 non-breaking。新增 required input／argument 需考慮 default。

既有 nullable input 改 NonNull，即使同時加 default，固定分類器仍列 breaking。既有 default 新增為 non-breaking，改動／移除為 dangerous。optional input／argument 新增保守列 dangerous。List／NonNull wrappers 依位置遞迴比較，非單看驚嘆號。
