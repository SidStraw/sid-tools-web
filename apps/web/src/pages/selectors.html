02 ／ 權重與命中，分開看

三元組 (ID, class／attribute／pseudo-class, type／pseudo-element) 逐欄比較，不是十進位分數。已知排名只比較 specificity；未評估／動態仍可有已知權重，未知／不支援不排名。命中不代表會贏。

不是完整 cascade：不處理 origin、!important、layers、scope proximity、source order、inline style、繼承與動畫。這也不是原始網頁、可視預覽或安全清洗後可部署的 HTML。

免登入。HTML／selectors 只在目前頁面記憶體，不上傳、不永久保存、不放進 query／hash／分享 URL；編輯、清除、重整或離開會丟棄結果。複製是你主動帶走的純文字，可能含敏感 id／attrs／selector，分享前請檢查。

支援範圍、安全省略與比對界線
  • 純 css-tree AST：ID／class／attribute／type、四種一般 combinators；:is／:not／:has 取參數最大 tuple，:where 為零，nth-child／nth-last-child 加 pseudo-class 1 與 of-list max。每個 top-level complex selector 各自 tuple；不猜哪個 logical argument 真正命中。貢獻來源可跳回原始 selector 範圍。
  • 動態 hover／focus／active／target／visited／validation／autofill／modal／fullscreen／media／defined 等只計已知權重，不比對狀態。pseudo-elements／namespaces 可有已知權重，但不嘗試元素命中。未知 function／pseudo、& nesting、nested :has、Raw／無法確認的 forgiving branches 不給假 tuple。Browser SyntaxError 與有效空命中分開；瀏覽器支援不會把 parser unknown 升級成排名。
  • HTML 離線 parse5@8.0.1，body context、scriptingEnabled:true（只影響解析，不執行 script）、source locations／tokenizer errors。樹建構修復（如隱含節點、錯置標記調整）可能沒有通知，並非完整 repair diagnostics。另以離線文件解析偵測被忽略的 html／head／body wrapper、屬性與 doctype，不用於比對。只有 document.implementation.createHTMLDocument('') 且 defaultView=null 的 factories；不把原始標記送進 DOMParser／innerHTML／srcdoc 等瀏覽器解析器，不 import／adopt／clone 到 live document。
  • HTML allowlist；script/link/meta/base/iframe/frame/frameset/object/embed/applet/param/audio/video/source/track/template/noscript/portal/fencedframe 與 foreign SVG／Math 根保留同標籤 childless placeholder，只留 id／class／data-*／aria-*／role。其子樹、未知／自訂元素及子樹不比對。style 無法安全保留（連空原生 style 都可能觸發 CSP），整個元素／子樹省略並明示 partial，不以假 namespace 代替。一般元素只保留 identity 與明確 allowlist 的文字／表單／結構 attrs；所有事件、style、src/srcset、srcdoc、資源／未核准 attrs 移除，href 只留在 inert a／area，絕不是真連結。
  • 偵測到的省略／placeholder／tokenizer 錯誤會記錄，樹修復不保證逐項通知；有通知時所有 selector 會有 partial 提醒，參照被移除 attrs／tags 另列特定警告。:not／:empty／關係可能被省略改變，0 命中也不保證原始 DOM 是零。Comments 不影響 :empty；whitespace text 仍保留於 inert 樹，結構清單只略過無內容的空白 row。
  • HTML 限制包含被省略的所有 AST 子樹／template content：2,000 elements、64 層、每元素64 attrs、每 attr value2,000、每 text node10,000字碼單元；任一超限整份拒絕，不顯示截斷樹當完整。原生單次 selector call 無法中斷；硬上限是主要防護，每 call>200ms 顯示 slow 提醒，整輪>2秒後剩餘不再嘗試，不當作零命中。
  • 目前 production E2E 的 native matching 以 Chromium 為證；其他瀏覽器 Level4／flags 支援可能不同。:checked／:disabled／:enabled／:default 等只反映 inert 初始結構，不是原頁面 live state。排名不含規則位置，element 顯示的「最高已命中 tuple」只取真的匹配的 top-level branches，不是 cascade winner。
  • 範例皆人工合成、非外部網頁或使用者資料。純文字結構 row 用文字與形狀標記命中，沒有渲染 HTML／CSS、hover 模擬、iframe、外部資源或 script 執行能力。
