版本的去留

版本宣告，不是相容性保證。

SemVer 範圍只檢查版本宣告，不保證實際 API 相容性。升級前請另查變更紀錄並執行測試；這裡不會安裝套件或查詢 registry。

01 ／ 先看最左邊的非零位

^1.2.3 允許到 2.0.0 之前；~1.2.3 只到 1.3.0 之前。0.x 不代表穩定 API：^0.2.3 到 0.3.0 之前，^0.0.3 只到 0.0.4 之前（上界皆排除其 prerelease）。

02 ／ prerelease 要明確納入

預設排除 prerelease，* 也不例外。同一個 OR 分支必須明寫相同 major.minor.patch 的 prerelease 條件；>=1.2.3-beta.1 可含 1.2.3-beta.2，但不會自動納入 1.3.0-beta.1。

語法、限制與資料處理

採 node-semver 7.7.3，loose=false、includePrerelease=false；建置資訊（+build）不影響匹配。版本清單上限 64,000 字元、500 筆；每範圍最多 512 字元、16 個 OR 分支、64 個條件詞。版本號數字須在 JavaScript 安全整數內。任一輸入無效就停止，不猜測或略過。

不支援 latest、workspace:、URL、逗號 AND 或其他套件管理器方言。所有計算都在瀏覽器記憶體執行，不上傳、不自動儲存、不產生分享連結。編輯即隱藏舊結果；清除、重整或離開頁面會丟棄輸入。下載 JSON 是你主動儲存的例外，包含原始輸入、固定引擎規則與每筆原因，可貼回頁面重現。
