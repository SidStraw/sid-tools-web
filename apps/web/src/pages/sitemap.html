01 ／ 貼上 Sitemap XML

貼上未壓縮文字，最多 2,000,000 UTF-8 bytes、10,000 個條目；不是 2 MB 的 UTF-16 字元數。Bytes 依輸入框文字量測；瀏覽器可能正規化換行，不等同原始檔案大小。超限不產生部分通過結果。拒絕 DOCTYPE／entity 宣告，不載入外部資源。URL 與查詢參數可能含秘密，請留意螢幕分享及下載。

貼上 XML，或先載入合成範例。

02 ／ 靜態檢查結果

這不是 HTTP 狀態或 Google 收錄檢查。Index 子檔只檢查連結文字與欄位，內容一律未檢查；不會自動載入。網址只顯示為文字，不提供點擊開站。

03 ／ 路徑與原始條目

樹依解析後的 origin／pathname 分組，查詢參數保留在清單；不是網站導覽關係或爬取結果。無效 URL 留在清單，不塞入路徑樹。

Sitemap 0.9 支援範圍與限制
  • 只支援 XML 1.0、UTF-8 文字、精確 namespace http://www.sitemaps.org/schemas/sitemap/0.9。根為 urlset 或 sitemapindex；直接子元素分別為 url／sitemap，欄位也須使用相同 namespace。可用 namespace prefix。拒絕 DOCTYPE／entity 宣告，即使宣告樣式文字位於註解或 CDATA 內；內建 XML 字元參照在此安全檢查後才解碼。
  • 每條目必須有一個直接 loc。可選 lastmod；urlset 另支援 changefreq（always、hourly、daily、weekly、monthly、yearly、never）與 priority（0–1 十進位）。Index 不接受 changefreq／priority。欄位去除首尾空白，不支援巢狀標記；重複欄位只保留第一值並明示不完整，不挑選有利值。
  • loc 為絕對 HTTP(S) URL，最多 2,047 UTF-16 字碼單元。不接受帳密、fragment、空白、反斜線、控制字元或無效百分比編碼。重複依去除首尾空白後的完整 loc 字串比較，不自動合併等價 URL；mixed host 依 URL 解析後 host（含非預設 port）與第一個合法 URL 比較，scheme 差異不算 host 不同，樹則依 origin 分組。
  • lastmod 支援 W3C Datetime 六種形式：YYYY、YYYY-MM、 YYYY-MM-DD，或完整日期加 Thh:mmTZD、 Thh:mm:ssTZD、Thh:mm:ss.sTZD。 時間必須帶 Z 或 ±HH:MM；秒可省略，秒的小數至少一位且受欄位長度限制。不接受 leap second；年份 0001–9999。檢查日曆與格式，不判斷是否為真實更新日。
  • 協定上限 50,000 條目、52,428,800 未壓縮 bytes；本頁較小的本機上限是 10,000 條目、2,000,000 UTF-8 bytes、100,000 個 XML 元素、128 層。normalized 欄位與 pointer 合計最多 2,000,000 UTF-16 字碼單元，每欄位最多 4,096。超限拒絕，不將截斷結果視為通過。過長原始字串可在編碼前拒絕，此時 byte 數標為未量測。
  • 圖片／影片／news／hreflang 等延伸標籤、未知子元素、非 namespace 宣告的屬性、mixed text、processing instruction、重複欄位及巢狀標記皆明示不支援或不完整，不靜默忽略。XML 語法錯誤只提供文件層級定位，不回顯瀏覽器解析器原文。
  • 來源 pointer 保留原始條目順序；行／欄位為原始文字的 UTF-16 位置，定位開啟標籤。缺漏欄位回到其條目。清單每頁 50 筆；樹每層分批顯示 60 節點，超過 12 層的剩餘路徑合併成一節點，不丟失清單條目。樹保留重複與 query 變體的條目數。
