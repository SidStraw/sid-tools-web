05 ／ 不支援與錯誤，逐項留下

COVERAGE ≠ DATABASE VALIDATION
Statement 覆蓋與支援邊界

    支援欄位型別的有界 lexical description、NULL／NOT NULL、命名 PK／FK、ordered composite keys、self refs、有限 MATCH／actions／deferrability。PK 顯示 not-null，但原始 NULL／NOT NULL 位置仍保留。DEFAULT／CHECK／UNIQUE／GENERATED／COLLATE／TEMP／IF NOT EXISTS／INHERITS／PARTITION 等不處理，不搜索被拒絕尾部猜後續 constraints。

    Lexer 辨識 doubled quotes、standard／E／ASCII dollar-tag strings 與 nested comments；非 ASCII unquoted、U&、ambiguous backslash／未終止 lexical remainder 停止，不猜 SET 影響。ALTER／DROP／SET 未執行且不改動已接受 CREATE snapshots。Complete 只是覆蓋此宣告子集，不是 DB validation 或 migration 最終狀態；空／純註解輸入也不是資料庫 schema 證明。
