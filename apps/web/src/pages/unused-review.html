如何判斷候選

    

      未使用是分析候選，不是刪除許可。動態 import、框架隱式入口與外部消費的 exports
      可能不在分析可見範圍；先確認 entry、project 及 plugin，再決定是否保留。
    

    

      已接受的項目需要理由與來源摘要。來源檔案改變會回到待審查；引擎、scope
      或設定指紋不同時，不能把舊基準直接當作通過依據。「已消失」只表示本次同條件分析不再回報，不代表已證明功能正確。
    

    

      不執行 runtime CSS coverage，不提供自動刪檔或修正。若要實際清理，應另外審查
      diff、保留回復方式並驗證建置。報告包含相對路徑、符號與審查理由，分享前請檢查。
