## Five acceptance criteria — evidence mapping

1. **Types/fields/arguments/enums/nullability:** inherited79 core cases plus built public contract, and production fixed demos/type-add-remove/browser classifications. Before/after actual sources remain inspectable; source locations are AST-provided UTF16 start/end-exclusive and1-based line/column, not JSON Pointer.
2. **Input/output classes and reasons:** visible inverse variance rules near summary. Output nullable→NonNull non-breaking, reverse breaking; input inverse. Defaults/optional additions follow pinned classifier conservatively. Browser tests exercise both directions and default changes/addition/optional argument, original reason rendered only as plain text. Non-breaking is not operational assurance.
3. **Invalid/unknown not safe:** syntax, unresolved extension, limit, unchanged custom directive and ambiguous mapping tests. `status:unknown` is independent of `counts.unknown`, including0. Invalid/limit changes are absent because comparison was not completed; zero never means safe. Complete means static coverage, even when breaking.
4. **Navigation/export/fixed examples:** actual interactions cover category filtering, exact source selection, candidate inspection, unmapped absence of fabricated links, side/type/search coordinates, argument/enum source selection, one-hop reference navigation and50-row pagination. Export requires explicit sensitive-name acknowledgement and uses only `exportSdlComparison()`, with failure path never exporting raw report. Download content excludes SDL/reasons/signatures/descriptions/defaults and preserves names, codes, mapping, coordinates/references/scope/limits. Names/IDs/coordinates remain sensitive, not anonymous.
5. **Local privacy/lifetime:** no login/upload/endpoint/storage/query/hash/share/input logging. Hostile strings in reasons/signatures remain text, no live img/script/iframe/dialog/sentinel/request. Edit/clear/run/dispose/reload and late-import guards drop old results and consent. Blob URLs revoked on timer/edit/clear/dispose; failure releases URLs and never falls back to raw export. Shared12route tests prove menu/reload/SSG/noJS/canonical/sitemap and lazy behavior.

## API and limitations

Built typed `@sid-tools/core/sdl` exposes inherited `compareSdl`, `exportSdlComparison`, `SDL_LIMITS`, `SDL_SCOPE` and report/location/category types. Uses inherited exact graphql17.0.2 catalog dependency; no dependency/lock/core source changes by designer. Page controller imports the public core only on Run; no aliases or eager GraphQL execution/parser imports.

Limits per side:100,000UTF16,10,000tokens,lexicaldepth24,ASTdepth64/nodes6,000,64types including extensions,500members,1,000direct references,interface depth16. Combined1,000changes. All-or-nothing limit/invalid conclusions, no truncated success. UI changes/coordinates/references/issues paginate50, candidate paths≤20 with actual candidateCount.

GraphQL.js returns code/reason only, no structured target. Core AST candidates can still be ambiguous; UI preserves exact/candidates/unmapped instead of parsing prose or choosing first candidate. Direct type references are bounded flat edges, not a transitive impact tree or usage proof. A built-in scalar can be unmapped with no SDL definition; no source fabricated. Schema-invalid metadata may remain inspectable, resource-limit projections may be absent. Static synchronous computation and source limits do not constitute an interruptible-worker or worst-case latency guarantee.

Custom directives (even unchanged), roots, otherwise unclassified changes remain unknown as core specifies. Custom scalar coercion, resolvers, client queries, execution/usage/data/authorization cannot be proven by SDL. Existing input nullability tightening with newly added default remains library-breaking; optional input/argument additions share dangerous/safe codes and are conservatively dangerous. Raw local signatures and reasons may contain arbitrary/sensitive strings, displayed with textContent only; export helper deliberately omits them, while names still remain.
