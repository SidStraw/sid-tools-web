### Accepted limitations

The PostgreSQL18 scope and resource/renderer bounds above remain intentional: no catalog/type/target uniqueness/identifier truncation/full dialect or migration-final-state validation. Unqualified identities remain candidates without search_path; qualified resolved-local bindings prove only declared input identity and existing ordered columns. Unsupported clause tails are not searched for later guessed FKs; an FK after CHECK on the same column can therefore remain unrecorded while the table is explicitly partial. One invalid FK invalidates that table's other bindings. Implicit PK derivation requires a structurally complete qualified target before relationship-resolution diagnostics and preserves actual PK provenance; other cases remain unresolved. Partial/invalid accepted snapshots export only with conspicuous incomplete labels, not compatibility guarantees. Large diagrams require native scrolling/zoom; display-budget failure refuses SVG rather than silently truncating it. Names/types remain potentially sensitive and consent-gated, not anonymized.
