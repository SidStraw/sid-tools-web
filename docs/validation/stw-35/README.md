## Decode/resource contract

- Single local file only; **nonempty ≤8,000,000 bytes**, **edge≤4096**, **decoded pixels≤4,000,000**. No remote URL field, file-system crawler, upload, persistence, server image service, new dependencies or CSP widening.
- JPEG/PNG/WebP only; signature inspected with existing public `@sid-tools/core/images` `inspectImage` helper **before** native decode/Blob creation. Nonempty MIME must match recognized content; empty MIME uses container inspection. GIF/SVG/unsupported MIME, APNG and animated WebP rejected, never silently first-frame extraction.
- Palette adapter applies its stricter4M/4096 limits on top of existing helper limits. It additionally refuses multiple JPEG SOF frames, repeated/inconsistent VP8X headers and mismatched/multiple WebP coded-frame dimensions rather than trusting canvas metadata alone. Unsupported/malformed images may still be refused by native decoder; the adapter is not a complete image-file validator or CRC verifier.
- FileReader aborts on cancellation. Native image load uses only a local typed Blob URL; callbacks/abort listener/timer detached on settlement.10seconds stops waiting for native image load; `src` removed and Blob URL revoked on completion/error/cancel/timeout. Browser-native decoder internal resource release is browser-controlled, not a promised immediate kill or hard CPU sandbox.
- Natural decoded dimensions checked again before pixel Canvas allocation; only exact container dimensions or swapped orientation dimensions accepted, within stricter edge/pixel caps. Extra decoded-size mismatch browser test rejects a mocked5000px width, no source preview allocated, URL released.
- sRGB Canvas reads8-bit RGBA at original accepted size, no decoding oversized sources then downscaling. Intermediate canvas cleared to0 after extraction; preview canvas and decoded pixel state discarded on source/run/cancel/clear/dispose. Native/profile/EXIF/premultiplication/HDR/wide-gamut browser behavior may differ; no cross-browser original-color fidelity promise.
- Browser tests exercise8MB/4096/4M bounds, MIME/content mismatch, unsupported type, file count, APNG, animated WebP, coded-frame mismatch **before Blob creation** (created count0), and malformed image failure with no output. Valid source recovery after errors is tested. PNG/JPEG/WebP actual successful decodes all tested.

## Sampling and compositing contract

- Explicit selected opaque RGB backing, **no hidden white default**. User can select white/warm-white/dark-forest or validated six-digit custom HEX. Fully transparent source pixels contribute backing samples rather than being dropped or retaining invisible original RGB.
- Fixed4-bit/channel buckets (4096maximum), representative rounded arithmetic mean of composited encoded-sRGB samples, count-descending/RGB-bucket tie order. Default10,000samples and8colors; UI supports1,000/10,000/100,000samples and8/16/32colors. Indices `floor(i×pixelCount/sampleCount)` may alias periodic patterns; not perceptual clustering/ML/exact unique colors/visual dominance or guaranteed full-image proportions.
- Frequencies use **all samples**, not returned bucket total.16-color synthetic PNG with8returned buckets reports8omitted samples and6.25% each; selecting16returns all16 with0omitted, without renormalization.
- Role inputs are **illustrative defaults**, visibly not inferred from source. Explicit swatch assignment sets chosen role to composited RGB/alpha1; manual inputs remain user-chosen HEX/alpha. Changing extraction backing/options recomputes palette and contrast but does not secretly reassign roles by bucket index. Changing source/run clears selected tokens and old results.
- Background RGBA over backing, then foreground/accent RGBA over rendered background, encoded-sRGB source-over. No whole-card opacity, linear-light blend modes or invented self colors. Preview style and contrast use exact opaque returned numbers, not rounded HEX. Alpha0text yields ratio1; failed outcomes remain readable in independent control chrome even when preview itself becomes difficult to read.
- Accent is evaluated **as text on surface**, not button background or full non-text UI certification. The preview is a labeled static visual sample, not an interactive dead-end button or automatic large-text classification.
- WCAG2.x luminance breakpoint0.04045, weights0.2126/0.7152/0.0722, ratio(lighter+0.05)/(darker+0.05). Unrounded ratio determines four flags; displayed ratio9significant digits only. Actual large-text conditions are separate18pt≈24CSSpx or14ptbold≈18.67CSSpx; no font inspection/accessibility inference.

## Token, safety and lifecycle contract

- Only explicitly checked text/surface/accent records passed to core serializer. Name subset lowercase ASCII kebab-case,1–64characters, unique, no leading`--`. No arbitrary selector/property/value or source string inserted into CSS. Invalid input yields a static message, no partially emitted CSS.
- Values are exact numeric **opaque resolved RGB**, retaining component fractions to match preview; not rounded HEX or silently alpha-dropped RGBA. UI explicitly states dependence on this backing/surface context. Failing selected combinations remain exportable with all failed thresholds shown; serialization is not a contrast certificate.
- Live full CSS preview is the same string downloaded as `selected-color-tokens.css`. No source bytes/metadata/name or unselected role data included. No auto-save/share/copy action or framework-specific export promised.
- Role/name/check/options edits revoke old download URL; valid edits regenerate current preview; invalid edits disable download. New export revokes predecessor. Replacement/demo/run/cancel/clear/dispose resets report, decoded pixels, canvas, selected tokens, derived colors and handlers. Revision guard stops late imports/demo generation/read/decode from restoring stale output; file abort/native cleanup separate from state guard.
- Browser tests track source URL revocation after successful decode, failures and cancel; download1active then0afteredit/replacement/navigation, no URL left after clear. Clear resets backing to unchosen and canvas0. SPA re-entry/history/reload starts fresh; pending lazy load after clear cannot resurrect results. Native-load timeout uses a held image-src setter and browser virtual clock; explicitly a lifecycle test, not a slow real image benchmark.
