## Worker and export architecture

`apps/web/src/openapi.worker.ts` imports PUBLIC `@sid-tools/core/openapi`; its only computation is pure synchronous `compareOpenApi`. Worker reply is plain clone-safe report, no parser AST/internal Maps. Worker request accepts only expected kind/id/string inputs, catches failure without echoing source/error text. A new module worker is instantiated only Run; no shared tools.worker/Cron fallback, no main-thread compare/parser call. Existing `worker-src 'self'` suffices. Controller owns20s timer and onmessage/error/messageerror handlers, terminates and nulls them on any terminal path; revision/worker identity plus reply shape checks reject stale/unexpected replies. Successful actual worker is observed closed, not merely labelled stopped.

Export explicit action can lazy-import public helper on main thread; it calls only `exportOpenApiSummary`, never comparator/parser. Consent checked again after import and revision checked before download. BlobURL revoked1s after download, or earlier on reset/dispose/error. Projection uses static codes/structural IDs (no value hashes), names/pointers, original locations/uses,counts/rules/limits. It is reduced, not anonymized: operation names/pointers may contain secrets. No automatic export/copy/upload.
