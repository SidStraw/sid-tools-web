## Isolation contract and bounded exception

Exact catalog app runtime **parse5@8.0.1** (2026-04-19 publication, older than4320-minute minimum), core runtime **css-tree3.2.1**, dev types **@types/css-tree3.2.0**. Generated pnpm lock only; age/trust/CSP/toolchain policy unchanged. parse5 body-context standards fragment uses locations and scriptingEnabled:true (parsing behavior, not execution). Source UTF16 offsets, tokenizer errors and implied elements are disclosed. `parse5:*` notices are tokenizer errors, **not exhaustive tree-construction repair diagnostics**; foster parenting, adoption-agency and implied/misplaced-node repairs may be silent.

After the same 50,000-unit prelimit, a second **offline** `parse5.parse(text, { sourceCodeLocationInfo: true })` is used only to detect explicit html/head/body start tags or wrapper attributes and doctype. Each detected wrapper/doctype creates a source-located `document-wrapper-ignored` notice; wrapper tags and attribute names enter omission metadata. Implied attribute-free wrappers do not trigger false notices. No wrapper attributes are carried over, no full-document tree is reconstructed or matched, and no browser HTML parser is used. Existing fragment matching remains the source of truth. These notices activate global partial results and every branch's partial warning even for empty matches; tag/attribute-reference warnings remain additional evidence, not an exact original-DOM claim.

Before reconstruction validate the entire AST including omitted/template subtrees: HTML≤50,000UTF16, elements≤2,000, depth≤64, attrs/element≤64, value≤2,000, text-node≤10,000. Whole-input rejection, no misleading truncated report. Selectors: one comma CSS list, newline is whitespace;≤20 branches,≤1,000 each including branch whitespace,≤20,000 total, nesting≤16 and AST≤2,048. Public core contract unchanged.

Only factories of separate `document.implementation.createHTMLDocument('')` with defaultView=null; never feed raw HTML to browser parsers or move input nodes into live DOM. Allowlisted normal HTML attrs only, no resource/event/style attrs; a/area href stays inert and is displayed solely as text in the app. Dangerous/foreign roots generally retain same-tag/namespace childless identity placeholders, custom/unknown roots and descendants omitted; every omission recorded, metadata reference warnings include all logical branches (also zero-weight `:where`). **HTML style is the bounded unrepresentable-element exception:** attaching even an empty native style to inert document emitted Chromium `style-src-elem` CSP. Entire style subtree is therefore omitted and marked partial, not namespace-substituted or CSP-exempted. Post-fix hostile test requires zero CSP events, not an allowlist.

This is partial reconstructed fragment matching, never exact original/live-page matching or an HTML sanitization product. Dropped attrs/children can change `:empty`, `:not` and relationships; form pseudos reflect initial copy states only. Scope is synthetic body; synthetic html `:root` isn't fragment first element. No complete-document doctype/quirks fidelity. Text-only preview omits whitespace-only rows while preserving whitespace in inert tree. Comments omitted, not relevant to `:empty`.

Native single queries cannot be interrupted; hard limits are primary control. Calls>200ms flag slow; after2s remaining eligible branches are not evaluated, not zero. Historical integration synthetic1,831-element/20-`:has` round131ms included input/render; post-M1 focused run117ms includes both offline passes (see below). These are local regression measurements, not a worst-case guarantee; this capture pass ran no new performance tests. Separate deterministic clock test proves slow/budget statuses.
